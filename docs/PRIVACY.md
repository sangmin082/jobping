# 잡핑 개인정보 처리방침

최종 수정: 2026-09-05

잡핑(JobPing)은 각 기업과 무관한 비공식 앱으로, 기업의 공식 채용 페이지에 공개된
경력 채용 공고를 모아 사용자가 등록한 키워드에 맞는 새 공고를 알려드립니다.

## 수집하는 정보

잡핑은 **로그인이 없고 개인을 식별하는 정보를 수집하지 않습니다.** 서버에 저장되는
것은 아래가 전부입니다.

| 항목 | 용도 | 보관 |
|---|---|---|
| 앱 설치 식별자 (무작위 UUID) | 구독 설정을 기기와 연결 | 앱 삭제·알림 해제 시 삭제 가능 |
| 푸시 알림 토큰 (Apple 발급) | 알림 발송 | Apple 이 토큰을 무효화하면 즉시 삭제 |
| 관심 회사·키워드 | 공고 매칭 | 사용자가 변경·삭제 |
| 알림 발송 기록 (설치 식별자 + 공고 ID) | 같은 공고를 두 번 보내지 않기 위해 | 7일 후 자동 삭제 |

이름, 이메일, 전화번호, 위치, 연락처, 광고 식별자는 수집하지 않습니다.
저장한 공고(북마크)는 기기에만 보관되며 서버로 전송되지 않습니다.

## 채용 공고 정보

공고의 제목·링크·게시일·근무지·직무명만 저장합니다. 공고 본문은 저장하지 않으며,
원문은 항상 각 회사의 공식 채용 페이지에서 열립니다. 잡핑은 채용 정보의 정확성을
보증하지 않습니다.

## 제3자 제공

수집한 정보를 제3자에게 제공하거나 판매하지 않습니다. 서버는 Amazon Web Services
(서울 리전)에서 운영됩니다.

## 삭제

설정에서 알림을 끄거나 앱을 삭제하면 이후 알림이 가지 않습니다. 서버의 설치 식별자와
구독 정보 삭제를 원하시면 아래로 연락 주세요.
